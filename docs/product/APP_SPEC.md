# Pocket · DSH 随行 — 产品与 UI 规格

> 状态：v0.3 UI 原型（可交互）
> 目标：把 DSH 手机端从「桌面网页缩小版」升级为面向普通用户的旗舰 App。

## 1. 定位

**Pocket 是 DSH 的手机遥控器，不是另一个聊天机器人。**

- 用户在电脑上跑 DSH，手机负责：看进度、批审批、继续对话、接收通知。
- 手机端不重新实现 Agent，只消费 DSH 的 Session / 事件流 / 审批 API。
- 第一优先是「信任感」：状态真实、断线可恢复、不丢消息、不假装成功。

## 2. 目标用户

| 用户 | 场景 | 关键诉求 |
|---|---|---|
| 个人开发者 | 通勤、床上、会议间隙看长任务 | 一眼看到是否卡住 / 是否需要批准 |
| 小团队 | 把 DSH 当内部 Agent 平台 | 多设备、可吊销、审计清晰 |
| 非技术用户 | 家人/同事代管一台 DSH | 不用理解 WebSocket、端口、隧道 |

## 3. 设计原则

1. **Chat-first**：首页就是输入框，不先让用户找会话。
2. **状态可见**：运行中、等待审批、已完成、失败、离线，永远有明确视觉状态。
3. **单手可达**：主操作在底部 1/3；审批按钮足够大；键盘弹出不遮挡输入。
4. **信息折叠**：工具输出、推理过程默认折叠；只把结论和待决策项推到前面。
5. **恢复优先**：任何断线/切后台都回到原位置，并提示「已恢复 / 可能遗漏 N 条」。
6. **克制的品牌**：深色、留白、少量蓝紫渐变；不使用 DSH 官方鲸鱼做 App 图标，避免冒充官方。

## 4. 信息架构

启动
- 已配对 → 首页
- 未配对 → 连接向导（扫码 / 输入地址 / 局域网发现）

首页
- 继续任务（进行中卡片）
- 最近会话
- 活动摘要（待审批）
- 底部 Tab：首页 / 会话 / ＋ / 活动 / 设置

会话
- 消息流（用户 / 助手 / 工具 / 审批）
- 加载更早
- 停止 / 排队 / 模型
- 返回

活动
- 待处理（审批）
- 进行中（运行中的会话/后台任务）
- 已完成

设置
- 连接（延迟、版本、重新同步）
- 通知 / 触感 / 外观
- 设备与安全 / 关于

## 5. 关键交互

### 首页
- 输入框自动聚焦（仅在用户主动点击「新建」时，避免一打开就弹键盘）。
- 发送后创建/复用会话，直接进入 Chat，显示乐观用户气泡。
- 「继续上次」把最近会话的第一条未完成提示填回输入框，不自动发送。
- 下拉刷新会话列表；顶部连接 pill 点击可手动重连。

### 会话
- 进入时先渲染 IndexedDB 快照（如有），再开 follow 流；快照与实时事件按 seq 去重。
- 默认滚到底部；用户上滑后不再强制跟随，出现「回到最新」。
- 工具卡片：tool/call 出现即插入；tool/result 到达后更新状态与输出，不新增一条消息。
- 审批卡片：approval/asked 插入；点击允许/拒绝调用 $events/result；approval/decided 后置灰。
- 断线：顶部出现「重连中」；恢复后重新打开 follow（拿到新 snapshot），按 seq 合并，不整页刷新。
- 切后台超过 30 秒：visibilitychange + pageshow + online 触发恢复；恢复失败才整页 reload。
- 停止：session/cancel，保留已生成内容；按钮立即变「停止中」。

### 活动
- 审批与运行中任务按会话聚合，不按事件刷屏。
- 允许/拒绝后就地移除并 toast；失败则回滚并提示原因。

### 设置
- 主题：深色 / 浅色 / 跟随系统，持久化。
- 同步状态：显示「已连接 · 18ms」、最后同步时间、待发送队列。
- 设备与安全：引导到电脑端设置卡，不在手机端提供「全部吊销」的危险操作。

## 6. 视觉系统

- 背景：深色 #07080B，顶部蓝紫径向光晕；浅色 #F5F6FA。
- 表面： #12151C / #171B24 / #1E2430。
- 主色： #5B7CFF → #8B5CFF；成功 #3DDC97；警告 #FFB454；危险 #FF6B7A。
- 字号：标题 30–38 / 正文 14.5 / 辅助 11–12。
- 圆角：卡片 22–28；消息气泡 20；按钮 12–16。
- 动效：220–320ms，cubic-bezier(.2,.8,.2,1)；尊重 prefers-reduced-motion。
- 图标：24px 线性图标，stroke 1.75；同一套 sprite 内联，离线可用。
- 触感：发送 8ms，审批 14ms；可在设置关闭。

## 7. 性能预算

| 指标 | 目标 |
|---|---|
| 冷启动首屏 | < 1.2s（4G，缓存可用） |
| 会话打开（缓存） | < 200ms |
| 会话打开（网络快照） | < 800ms |
| 事件到达 → 渲染 | < 80ms |
| 长列表 | 只渲染最近 100 条，向上分页 |
| 单条工具输出 | 折叠态不渲染正文；展开超过 8KB 截断并提示 |
| 断线恢复 | 3 次指数退避（0.5/1/2s），之后手动重连 |

## 8. 同步模型（摘要）

- **RPC**：POST /api/<method>，envelope {type:'client-request', rpcId, method, payload:{args}}。
- **会话快照 + 增量**：/api/remote.mux WebSocket，open → session/follow；首帧 snapshot，之后 event 帧，seq 连续。
- **审批**：$events 流首帧 ready，waterfall 帧回答 $events/result；emit 帧更新状态。
- **恢复**：重连即重新 session/follow 拿新 snapshot，按 seq 合并；不依赖服务端断点续传。
- **不轮询**：活动与会话状态由 $events 的 api-session/* 事件驱动；仅兜底健康检查每 30s。
- 详细时序见 [SYNC.md](SYNC.md)。

## 9. 安全与隐私

- App 只持有设备 cookie；不接触 DSH launch token / 上游签名 cookie。
- 所有公网访问必须 HTTPS；本地 HTTP 仅限可信局域网。
- 通知内容不含完整工具参数/文件内容，默认只显示工具名与会话标题。
- 设置页提供「在电脑端吊销本设备」的指引；吊销后 WebSocket 立即断开。
- 不接入第三方统计；崩溃日志默认留在本机。

## 10. 交付形态

1. **PWA**：立即可用，安装到主屏幕；离线壳 + 推送。
2. **Android App**：Capacitor 包装同一套 Web 资源；原生启动图、状态栏、通知渠道、分享入口。
3. **iOS**：复用同一套 Web 资源；需要 macOS/CI 签名，后续阶段。
4. **GitHub**：MIT 许可；CI 跑单测 + 构建 PWA + Android debug APK；Release 附 APK。
