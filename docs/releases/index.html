第一次使用

从零开始 · 大约 5 分钟
1

电脑装 Host

下载 ZIP，解压，双击 install.bat。装完后完全退出 DSH，再重新打开。

2

电脑登录 Tailscale

DSH 设置 → 手机 → 点「登录 Tailscale」，用浏览器完成授权。没有账号就先在 tailscale.com 注册。

3

手机装 App 并登录

安装 APK，打开 Pocket，点「在浏览器登录 Tailscale」，用和电脑完全相同的账号，允许 VPN。

4

等自动发现

App 会在 tailnet 里找电脑，找到后直接打开 Pocket。不需要输入 IP、端口或配对码。

常见问题

手机和电脑一定要在同一个 Wi-Fi 吗？

不用。连接走 Tailscale tailnet，手机用蜂窝网络也可以。只要两台设备登录同一个 Tailscale 账号。

为什么看不到电脑？

先确认电脑端 DSH 的「手机」卡片显示 Tailscale 已登录，再确认手机 App 里登录的是同一个账号。两边都在线后，App 会自动发现；也可以点「检查连接」重试。

更新会丢登录吗？

覆盖安装不会。登录状态存在 App 私有目录；只有卸载、清除 App 数据或主动退出才会丢。

没有电脑 / 没有 DSH 能用吗？

不能。Pocket 是 DSH 的手机端，需要一台运行 DSH 的电脑作为 Host。
