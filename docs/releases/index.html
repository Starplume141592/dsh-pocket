当前公网入口

手机和电脑必须能访问同一个地址；换地址后需要在 App 里重新填写。
—

第一次连接

  1. 在电脑上打开 DSH → 设置 → 连接手机，生成配对二维码。
  2. 手机打开上面的地址 → 扫码配对 → 批准后进入 Pocket。
  3. 安装到主屏幕（PWA）或装 Android APK；下次直接从图标打开。
